# BreathDeck — Implementation Plan

Companion to SPECIFICATIONS.md (requirement IDs referenced). Update status here after every change. Fuller background research: the original BreathFlow plan (project store `docs/breathflow-plan.md`).

## Architecture & key decisions
- `src/engine/` plain TS, no React. `AudioEngine` (context, gain chain: voice → volume → mute → transport → route → destination), `Scheduler` (lookahead, Worker tick 25 ms, horizon 0.25 s visible / 4 s hidden, schedules whole phases, cancels future cycles on change, resync on stall; its queue doubles as the UI timeline), `voice.ts` (`createVoice`: one breath with cosine fade in/out, shared by the engine and the offline render test), `OutputRouter` (setSinkId).
- `src/pattern/` `timing.ts` pure math; `PatternSource` interface (`ManualSource` V1).
- `src/samples/` `TakeRepository` + IndexedDB impl, `analyse.ts` (mono, HP, trim, normalise to per-style targets, flags), `SampleLibrary` (own takes from IndexedDB + bundled samples from `public/samples/manifest.json`, never persisted; `sourceFor(style)` = own › sample › none; per-style use/swap prefs in localStorage `breathdeck:v1:samples`; take pick by length + stretch), `stretch.ts` (WSOLA, offline, cached).
- `public/samples/` bundled CC0 takes, generated by `scripts/build-samples.py` (dev-only: python3, numpy, ffmpeg; re-checks CC0 on each Freesound page, slices HQ previews into takes, writes manifest with credits).
- `src/recording/` mic capture (AudioWorklet PCM, processing off), `segment.ts` in/out split, `RecordingSetup` wizard.
- `src/state/` zustand store, presets, persistence. `src/ui/` components: `kit.tsx` (Button, IconButton, Card, Segmented, Slider, Switch, Badge, Dialog, icons), `Controls.tsx` (Rhythm/Sound/Preset cards, transport), `BreathCircle.tsx` (circle + phase ring + phase strip, rAF against audio clock minus output latency), `Panels.tsx` (Sounds with Sample/Your recordings/Upload tabs, Speaker), `RecordingSetup.tsx` (Set up → Record → Review), `App.tsx` (header, stage, welcome, Live Mode).
- Decisions: own recordings primary; stretch via in-repo WSOLA (offline, 0.75–1.33×, no GPL deps); pause = fresh inhale on resume; style change next phase; quick-picks keep holds; "Same as Mac" speaker default.

## Testing & validation
- Automated: `npm test` (Vitest): timing property checks, scheduler against fake AudioContext (event times exact, no overlaps, next-cycle changes), segment split, WSOLA length/pitch/level.
- `npm run e2e` (needs `npm run dev` running and Chrome at `/usr/local/bin/google-chrome` or `CHROME=`): `e2e-smoke` (transport, rate sweep, style switch, 0 late events), `e2e-record` (fake mic prompt → own takes replace samples), `e2e-audio` (8 pattern/style renders with the real samples: breaths ≥ −45 dB, holds < −70 dB, voice edges < 0.01, peak < 0.99, Connected gap < 100 ms at fast rates; live engine tapped by AnalyserNode: sound in in/out, silence in holds), `e2e-ui` (welcome on first run, samples active, no scroll at 1280×800 and 1440×900 in both themes, screenshots to `/tmp/bd-ui-*.png`).
- Manual Mac checklist: record guide on MacBook mic; speed sweep 3→40→3; style switch mid-breath; Spotify alongside with independent volume; Bluetooth Google Home (Same as Mac + chosen speaker, disconnect fallback); hidden tab 10 min; 60-min session; Live Mode at 1280×800.

## Status & outstanding issues
- Redesign (2026-10-28) done. `npm test` (22) and `npm run e2e` pass in headless Chrome. Verified against SND-7/8/10, UI-7, AUD-9/10: samples load for all four styles and are used by default; own takes override per style; welcome, Sounds tabs, recording stepper, both themes and Live Mode checked by screenshot; main screen fits 1280×800 and 1440×900.
- Rendered levels with samples at 70 % volume: about −28 dB RMS (Soft) to −22 dB (Powerful) during breaths, peaks ≤ 0.46.
- **Not verified on real hardware** (no audio device in build VM): how it sounds by ear, sample in/out labelling (automatic; per-style Swap in/out provided), stretch quality, Bluetooth/Google Home routing, Spotify alongside, hidden-tab 10 min, 60-min soak. Run the manual checklist.
- Deviations from SPECIFICATIONS: uploaded files are stored as processed mono WAV (not original blob); the `breathing_sounds.m4a` fixture is imported via Sounds → Upload → "In + out file"; no separate per-style intro screens (style blurb shown on each prompt); Pause is a 150 ms fade then freeze (resume = fresh inhale) as specified.
- Known gaps: Connected with sample sounds leaves a short quiet turnaround (~0.35 s) at slow rates (e.g. 2 s phases) because the source breaths are short; own recordings at 1/2/4/6 s avoid it. Samples are 128 kbps previews (originals need a Freesound login). Zip export/import (SND-6 partial); no AudioWorklet tick fallback; "Hear it in rhythm" preview in the review grid not built; `navigator.storage.persist()` not requested yet.
